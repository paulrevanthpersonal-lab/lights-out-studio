# Game design

Every generated board begins from an all-dark solved state and applies deterministic legal moves. The solver enumerates every possible first row, propagates forced moves downward, and selects the smallest valid solution. Difficulty changes board size rather than silently changing rules. A hint reveals one move from the verified solution so the player keeps agency.

The visual language references circuit diagnostics: signal-green lights, a session log, instrument readouts, and strict monospace labels. It intentionally differs from the commerce and infrastructure projects in the portfolio.
