# Game design

Every generated board begins from an all-dark solved state and applies valid moves. Reversing those moves proves a solution exists. Difficulty changes board size rather than silently changing rules. The single hint highlights an active signal without auto-solving the board, so the player retains agency.

The visual language references test equipment: signal-green lights, a session log, instrument readouts, and strict monospace labels. It intentionally differs from the commerce and infrastructure projects in the portfolio.
